# GRIZZLY — карта для Telegram Mini App

Карта San Andreas для бота сервера GRIZZLY (MTA:SA). Открывается из бота командой /map.

- `map.jpg` — радар-карта, собрана из файлов игры (gta3.img, radar00–143.txd).
- `heightmap.bin` (и `.gz`) — высота земли (нижняя поверхность — земля, а не крыши): 3000×3000 клеток по 2 м, uint16 LE, значение = (z + 100) × 10. Используется сервером, странице не нужна.
